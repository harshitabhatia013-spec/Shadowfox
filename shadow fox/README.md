# Personal Portfolio Website — ShadowFox Frontend Internship Task

A modern, responsive personal portfolio website built for the **ShadowFox Frontend Developer Internship (Beginner Level Task)** by **Harshita Bhatia**.

---

## 📌 Project Overview

This repository contains the source code for a personal portfolio website designed to showcase frontend development skills, UI design choices, responsiveness, and clean code structure.

### Key Sections Included:
- **Home / Introduction Section**: Widescreen hero layout with role statement, call-to-action buttons, portrait photo frame, and education details.
- **About Section**: Personal background, academic focus (B.Tech AI & Data Science at CTAE Udaipur), NCC discipline, and hackathon milestones.
- **Skills / Tools Section**: Technical competencies covering HTML, CSS, JavaScript, Python, C++, SQL, Git, and GitHub.
- **Services Section**: Overview of frontend development & responsive web design capabilities.
- **Projects Section**: Showcase of frontend projects built with clean web technologies.
- **Achievements Section**: Hackathon awards, NCC training, and academic background.
- **Contact Form**: Interactive contact form featuring client-side JavaScript input validation and instant feedback.
- **Fully Responsive Layout**: Mobile-first media queries supporting Desktop, Tablet, and Mobile devices.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure & accessibility attributes (`portfolio.html`).
- **CSS3**: CSS Custom Variables, Flexbox, CSS Grid, Glassmorphic UI cards, smooth keyframe animations, and media queries (`styles.css`).
- **JavaScript (ES6+)**: Sticky navbar scroll effect, active link highlight via `IntersectionObserver`, mobile drawer menu, scroll reveal animations, and form validation (`script.js`).

